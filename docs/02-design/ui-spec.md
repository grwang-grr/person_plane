# 页面设计基准

以用户提供的 Plane Work 二级侧栏截图为外观参考，保留白色侧栏、灰色圆角选中态、线性图标、紧凑间距与项目分组。移除商业试用区、第三方连接、AI 等入口；草稿、你的工作、便签独立页与更多已按最新确认恢复，首页也展示彩色便签。

当前骨架采用一级 72px、二级 264px 的桌面初始宽度，属于可调整的实现值，并非用户确认的尺寸。二级可折叠，项目快捷分组可折叠。项目内模块改为项目快捷条目下的左侧展开菜单，参照 Plane project-navigation.tsx，不再采用顶部标签。首页、草稿页和双栏弹窗已进行浏览器视觉检查。

页面统一包含标题、说明、必要操作和内容区；空数据、加载、错误和不存在页面需要明确区分。首页已替换统计占位卡，采用 Plane 的 750px 居中内容区、近期列表与彩色便签，并加入我的操作。后续功能应使用统一设计变量维护颜色和尺寸。

具体字号、配色与布局数值见 [你的工作页面对照](your-work-layout.md)。全局已加载同款 Inter Variable 字体，继续使用 Propel 的系统中文回退栈。

基础组件使用 Propel，按当前仓库规范进行组件组合。文字全部使用中文，保留格式名、技术名称和用户输入。交互必须具备键盘操作、可访问名称和可见焦点。

参考源码位于相邻 planee 工程的 components/navigation、components/sidebar、components/workspace/sidebar 和 components/base-layouts。没有复制相邻工程的账号、工作空间或权限逻辑。
