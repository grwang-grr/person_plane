# 数据模型边界

本文件描述业务对象的职责，其中项目、任务、便签、操作记录、近期访问已通过 0001_workspace 迁移落地，其他对象尚未建表。字段、约束和枚举要在功能开发前确认，随后通过迁移落地。

| 对象       | 职责及关系                                                 |
| ---------- | ---------------------------------------------------------- |
| 项目       | 管理目标和项目生命周期，包含任务、周期、模块、文档及里程碑 |
| 任务       | 归属一个项目，可有父任务；保存状态、优先级、日期和进度     |
| 周期       | 将任务安排到一段时间内，区别于项目阶段                     |
| 模块       | 按功能或交付范围关联任务                                   |
| 视图       | 保存任务的展示、筛选和分组配置                             |
| 文档       | 保存项目说明和记录                                         |
| 里程碑     | 关键目标、目标日期及关联任务                               |
| 附件       | 记录文件元数据和所属项目、任务等业务对象                   |
| 问题与风险 | 记录影响及处理情况；具体拆分方式待确认                     |

计划是任务日期与安排的展示和操作入口，是否另建计划实体需要先明确业务语义。业务中不引入用户、团队、项目经理或周报。

父子任务须防止循环和跨项目关联；附件只能通过系统管理和查找。删除、归档和恢复策略需在实现时统一定义。
