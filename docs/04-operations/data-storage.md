# 数据和存储

| 目录             | 用途                           |
| ---------------- | ------------------------------ |
| data/database    | SQLite 数据库和运行时 WAL 文件 |
| data/attachments | 附件文件                       |
| data/backups     | 数据备份                       |
| data/logs        | 应用日志                       |
| data/tmp         | 本工程临时文件                 |

环境变量 WPLANE_DATA_ROOT 支持改到其他磁盘目录。相对路径以工程根目录为准，不依赖启动脚本的调用位置。真实数据不纳入 Git。

当前仅提供 LocalFileStorage 基础适配；附件上传、下载 API、元数据表、文件类型限制和业务归属校验尚未开发。最终采用本地目录还是已有 RustFS 仍待用户确认，后续通过存储接口适配。

备份功能尚未实现。实现时必须使用 SQLite 一致性备份，并保持附件与元数据一致；不能在数据库运行时只复制 sqlite3 单文件，也不能只备份附件。恢复前应验证格式版本和备份完整性。
